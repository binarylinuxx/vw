## Анимации (tweens)

```cpp
const double x = vw::animate("panel.x", open ? 0 : -320,
                             {.duration = 0.45, .easing = vw::Easing::out_expo});
```

`vw::animate(id, target, options)` возвращает текущее значение и движется к `target`. Смените цель на лету — и движение продолжится с того места, где оно сейчас. Пока хоть одна анимация движется, сборка сообщает `animating`, и поверхность продолжает получать кадры; когда все остановились, кадры прекращаются.

| Параметр | Значение |
| --- | --- |
| `duration` | секунды; `0` — мгновенно (удобно, пока палец тянет) |
| `initial` | начальное значение, когда id встречается впервые — `initial = 0` делает появление с роста |
| `easing` | `linear`, `in_out_cubic`, `out_cubic`, `out_quint`, `out_expo`, `out_back`, `bezier`, `spring` |
| `bezier` | контрольные точки `{x1, y1, x2, y2}` для `Easing::bezier` |
| `mass`, `stiffness`, `damping` | для `Easing::spring`, сохраняет скорость при смене цели |
| `min`, `max` | ограничивают значение |

Новый id на каждое появление перезапускает анимацию: вход, который должен проигрываться при каждом появлении экрана блокировки, может использовать `std::format("lock.intro.{}", count)`.

Для эффектов, которые не являются анимацией к цели, — пульсации, тряски — вызывайте `vw::request_animation_continuation()`, чтобы получить ещё один кадр.

## Наведение

`input.hover = vw::Hover{.color = …, .scale = 1.02, .duration = 0.16}` тонирует и масштабирует виджет, пока над ним указатель, без пересборки. `input.on_hover(bool inside)` сообщает о входе и выходе, даже если поверх что-то нарисовано, а сцена после этого пересобирается — так открывают всплывающие при наведении панели.

## Перетаскивание

```cpp
.input = {
  .on_drag_start = [&](const vw::DragEvent&) { dragging = true; },
  .on_drag = [&](const vw::DragEvent& d) { offset = d.x - d.start_x; },
  .on_drag_end = [&](const vw::DragEvent& d) {
    dragging = false;
    if (!d.cancelled && std::abs(offset) > width * 0.3) dismiss();
    offset = 0;
  }}
```

Перетаскивание захватывает указатель от нажатия до отпускания, даже если он ушёл с виджета или сцена под ним пересобралась. События несут `x`, `y`, `start_x`, `start_y`, `dx`, `dy` (с прошлого события), `button` и `cancelled` (Escape отменяет, пока у поверхности фокус). `drag_button` выбирает кнопку мыши (по умолчанию BTN_LEFT).

Пересборки при перетаскивании объединяются по frame callback'ам — не больше одной за кадр (и минимум раз в 33 мс, если композитор кадров не шлёт).

<Callout type="tip" title="Следовать, потом успокоиться">
Пока тянут, передавайте указатель напрямую с `duration = 0`; при отпускании переключайтесь на пружину или `out_back` к положению покоя. Анимация подхватит с того места, где палец её оставил.
</Callout>
