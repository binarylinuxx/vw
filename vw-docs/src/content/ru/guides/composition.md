## Порядок рисования

Примитивы рисуются в том порядке, в котором вы их создаёте, включая текст и картинки. Нарисуйте панель после текста — и панель его закроет. Сначала фоны, потом их содержимое, потом оверлеи.

## Обрезка виджета

Диапазон любого виджета можно обрезать после того, как он построен:

```cpp
const vw::Widget card = /* прямоугольники, текст, картинки … */;
ui.clip(card, {.x = x, .y = y, .width = w, .height = shown_height, .radius = 24});
```

Всё в диапазоне, вместе с его вводом, обрезается по скруглённому прямоугольнику; примитивы целиком снаружи скрываются. Так содержимое карточки остаётся внутри неё, пока её высота анимируется. Один примитив можно обрезать и при создании через `place.clip`.

Чтобы собрать один виджет из нескольких вспомогательных функций, возьмите их в скобки: создайте `hit_area` нулевого размера до и после и возьмите диапазон между ними — или используйте раскладку (`stack`, `column`), которая возвращает один виджет.

## Затухание виджета

```cpp
ui.fade(card, 1.0f - std::abs(swipe) / width);
```

`fade` умножает непрозрачность всего в диапазоне — заливок, градиентов, рамок, текста и картинок, — так что вся карточка может гаснуть, пока её смахивают.

## Форма картинок

`ImageProps` даёт несколько способов придать картинке форму:

| Свойство | Эффект |
| --- | --- |
| `radius` | скруглённые углы |
| `fit` | `stretch`, `contain` (с полями) или `cover` (обрезка по центру) |
| `mask` | замкнутый многоугольник `x0, y0, x1, y1, …` от 0 до 1 по картинке, со сглаживанием; кривые сначала разбейте на достаточное число точек |
| `tint` | умножает цвет |
| `effect.saturation` | 1 без изменений, 0 серая, больше 1 ярче |
| `effect.hue_rotate` | градусы по цветовому кругу |
| `effect.colorize`, `colorize_amount` | перекрашивает по яркости, сохраняя тени |

```cpp
ui.image({.path = cover_art, .width = 96, .height = 96, .fit = vw::ImageFit::cover,
          .effect = {.saturation = 0.6f, .colorize = theme.primary, .colorize_amount = 0.3f},
          .mask = scalloped_polygon, .place = {.x = 16, .y = 16}});
```

Картинки декодируются и вписываются один раз на файл, время изменения, режим вписывания и размер, так что перемещение или обрезка картинки в каждом кадре не декодирует её заново — а вот анимация её размера декодирует.
