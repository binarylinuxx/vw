Каждый пример — один файл C++, который собирается вместе с vw (`-DVW_BUILD_EXAMPLES=ON`, по умолчанию) и запускается сам по себе. Каждый достаточно короткий, чтобы скопировать его в свой проект и переделать.

```sh
cmake -S . -B build -G Ninja && cmake --build build
./build/vw-example-clock
```

## Виджеты рабочего стола

<Example name="clock" title="Часы" shows={['Layer::bottom', 'click-through', 'refresh_interval']}>
  Приветствие, время и дата на полупрозрачной карточке в левом верхнем углу. Лежит под окнами, никогда не принимает ввод и пересобирается раз в секунду.
</Example>

<Example name="dock" title="Док" shows={['vw::applications', 'themed icons', 'Hover']}>
  Закреплённые приложения вдоль нижнего края. Иконки берутся из desktop-файлов и темы иконок, клик запускает приложение.
</Example>

<Example name="calendar" title="Календарь" shows={['std::chrono', 'on_scroll', 'grid layout']}>
  Сетка месяца в правом верхнем углу. Стрелки или колёсико мыши листают месяцы, сегодняшний день подсвечен.
</Example>

<Example name="bar" title="Панель" shows={['full-width surface', 'exclusive_zone', 'Hyprland events']}>
  Верхняя панель во всю ширину: активное рабочее пространство, часы и кнопка лаунчера. Пересобирается сразу по событиям Hyprland.
</Example>

<Example name="status" title="Строка состояния" shows={['tray', 'network', 'bluetooth', 'upower', 'brightness']}>
  Системные сервисы в одной панели. Иконки трея открывают меню во всплывающем окне, яркость меняется прокруткой, а чип переключает профиль питания.
</Example>

## Оверлеи

<Example name="launcher" title="Лаунчер" shows={['two surfaces', 'Keyboard::exclusive', 'listview']}>
  Панель со всплывающим лаунчером, обе в одном приложении. Попап появляется при открытии, забирает клавиатуру и фильтрует приложения по мере набора.
</Example>

<Example name="power" title="Меню питания" shows={['fill the output', 'Layer::overlay', 'keyboard']}>

<Example name="calculator" title="Калькулятор" shows={['anchor::center', 'Keyboard::exclusive', 'grid layout']}>

</Example>
