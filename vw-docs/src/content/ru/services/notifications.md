---
title: Уведомления
description: vw — демон org.freedesktop.Notifications. Он владеет моделью — открытые, всплывающие, сохранённые, — а оболочке остаётся её только нарисовать.
---

```cpp
vw::notifications::start();   // занимает имя на шине, если его не занял другой демон
app.on_event(vw::notifications::event_fd(), vw::notifications::drain_events);

for (const auto& n : vw::notifications::popups())  draw_popup(n);
for (const auto& n : vw::notifications::history()) draw_in_centre(n);
```

## Жизненный цикл

| Что происходит | Состояние после |
| --- | --- |
| приходит `Notify` | открыто; всплывает (с режимом «не беспокоить» — только критические) |
| `hide_popup(id)`, `hide_popups()`, включение «не беспокоить» | открыто, больше не всплывает, сохранено |
| истёк таймаут | закрыто (причина 1), сохранено |
| `dismiss(id)`, нерезидентное действие, `clear()` | закрыто (причина 2), удалено |
| отправитель вызвал `CloseNotification` | закрыто (причина 3), удалено |

Временные (transient) уведомления никогда не сохраняются. История хранит не больше 256.

## Чтение

| Функция | Возвращает, новые сначала |
| --- | --- |
| `list()` | открытые уведомления |
| `popups()` | то, что сейчас должно всплывать |
| `history()` | то, что хранит центр уведомлений |
| `generation()` | счётчик, растущий при каждом изменении |

Каждый список — кэшированный снимок, который перестраивается только после изменения, а иконки темы ищутся один раз на уведомление, так что вызывать их в каждой сборке дёшево. Вызывайте их из потока отрисовки.

## Действия

| Функция | Эффект |
| --- | --- |
| `dismiss(id)` | пользователь закрыл уведомление |
| `hide_popup(id)`, `hide_popups()` | перестать всплывать |
| `invoke(id, key)` | шлёт `ActionInvoked`; затем закрывает, если уведомление не резидентное |
| `activate(id)` | действие по умолчанию: `default`, если есть, иначе единственное действие |
| `clear()` | закрывает всё |
| `set_do_not_disturb(bool)`, `do_not_disturb()` | включение прячет текущие всплывающие |

## Notification

`id`, `app_name`, `app_icon`, `summary`, `body` (может содержать подмножество разметки из спецификации), `actions` (`{key, label}`), `urgency` (0–2), `value` (подсказка прогресса, −1 если нет), `category`, `desktop_entry`, `resident`, `transient`, `action_icons`, `popup`, `closed`, `close_reason`, `timestamp` (секунды Unix), `expire_timeout` (мс; 0 — никогда).

`icon` и `image` — готовые к рисованию пути: иконка приложения (из `app_icon` или desktop-файла) и собственная картинка уведомления (`image-data`, записанная в PNG, который живёт вместе с уведомлением, или `image-path`).

## Поведение по спецификации

- `replaces_id` заменяет на месте и всегда возвращается как id.
- Синхронный тег (`x-canonical-private-synchronous`, `x-dunst-stack-tag`, `synchronous`) заменяет открытое уведомление с тем же тегом от того же приложения — на этом держатся индикаторы громкости и яркости.
- Таймаут по умолчанию 5 с; критические висят, пока их не закроют; явный 0 никогда не истекает.
- Возможности: `actions`, `body`, `body-markup`, `icon-static`, `persistence`.
