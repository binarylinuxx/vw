```lua
-- init.lua
local base = require("vw.base")
local surface = require("vw.surface")
local datetime = require("vw.datetime")

base.rectangle({ width = 160, height = 48, radius = 24, color = { 0.15, 0.23, 0.3, 1 } })
base.text({ text = datetime.format("%H:%M"), font = "sans", size = 18,
            color = { 0.82, 0.9, 1, 1 }, x = 54, y = 13 })
surface.set({ anchor = "top", margin = { 10, 0, 0, 0 } })
```

```sh
vw -c init.lua            # запустить
vw --check -c init.lua    # собрать один раз и сообщить об ошибках, Wayland не нужен
```

## Как это работает

Весь файл — это функция сборки: он выполняется снова при вводе, при событиях и каждые `refresh_interval`. Сохранение файла — или любого `.lua`/`.js` рядом с ним — перезагружает его; SIGHUP принудительно перезагружает. При ошибке на экране остаётся последняя рабочая сцена, а место ошибки печатается.

Виджеты повторяют свойства C++ с ключами в snake_case; цвета — `{ r, g, b, a }` от 0 до 1, а `x`/`y` лежат прямо в таблице, а не в `place`. Состояние, которое должно переживать пересборки, кладите в переменные уровня модуля или в `vw.animation`.

## Состояние, переживающее перезагрузку

Таблицы модулей пересоздаются при перезагрузке, поэтому долгоживущее состояние держите в глобальных переменных с защитой (`state = state or {}`) или в самом vw: текстовые поля, прокрутка и анимации хранятся по id и переживают перезагрузки.
