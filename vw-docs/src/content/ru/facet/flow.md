## for

```facet
for app in state.apps key app.id {
    ui.Text(text: app.name)
}
```

`for` повторяет своих детей для каждого элемента любого диапазона C++. `key` задаёт, что идентифицирует элемент: по нему Facet привязывает [анимации](/ru/facet/animation/) и элементы управления, так что они следуют за элементом, когда список меняет порядок. Без `key` используется позиция элемента.

## if

```facet
if state.loading {
    ui.Spinner()
} else if state.error != null {
    ui.Text(text: state.error, color: "#fa746f")
} else {
    ui.Text(text: "Готово")
}
```

Ветка может ничего не рисовать; раскладки вокруг справятся с пустым списком.

## let

```facet
for metric in state.metrics {
    let critical = metric.value >= 90
    ui.Text(text: metric.name, color: critical ? "#fa746f" : "#dfe6ee")
}
```

`let` даёт имя значению для элементов после него в том же блоке.

В начале файла, вне всех view, `let` создаёт константу, которой может пользоваться любой view файла:

```facet
let gap = 10
let accent = "#a7cbe7"

view Bar(state) {
    ui.Text(text: state.title, color: accent)
}
```

## Имена элементов: id

`id:` с простым именем даёт элементу имя. Его дети и элементы после него в том же блоке читают его свойства через это имя, так что размеры и положения могут зависеть друг от друга, а не повторяться числами:

```facet
S.Surface(id: panel, width: 200, height: 100) {
    S.Text(text: "Привет", place: { x: 20, y: gap })
    // внизу по центру панели, какого бы размера она ни была
    S.Button(label: "Нажми",
             place: { x: (panel.width - 120) / 2, y: panel.height - 24 - gap })
}
```

Имя обозначает свойства элемента: то, что ему передали, плюс значения по умолчанию его структуры свойств, как их видит C++ (`panel.width` — это `SurfaceProps::width`). Это не измеренная раскладка, поэтому ширину Text через его id не узнать. Два элемента в одном блоке не могут иметь одно имя.

У элемента управления `id: "search"` (строка) или переменная по-прежнему задаёт ключ его состояния; элементу даёт имя только ещё не занятое имя.
