## Значения

| Пишете | Значит |
| --- | --- |
| `12`, `0.5`, `"text"`, `true`, `null` | числа, текст, булевы значения, `std::nullopt` |
| `"#20272c"`, `"#a7cbe7f0"`, `"transparent"` | цвета; `vw::Color` из C++ в области видимости тоже подходит (`color: accent`) |
| `bold`, `space-between`, `contain`, `overlay` | имена перечислений, проверяются по свойству |
| `"100%"` | [относительный размер](/ru/facet/layout/#относительные-размеры) |
| `[a, b, c]` | список |
| `state.items`, `items[0]`, `format_bytes(n)` | поля, индексы и вызовы: обычный C++ |
| `items.length` | размер списка |
| `screen.width`, `screen.height`, `screen.name` | монитор, на котором рисуется view (а также `x`, `y`, `scale`, `refresh` в Гц); с [`App::per_output`](/ru/guides/shells/#панель-на-каждый-монитор) — у каждой панели свой |

## Операторы

Арифметика (`+ - * / %`), сравнения, `&&`, `||` и `!` работают как в C++. `+` с текстом с любой стороны склеивает: `"CPU " + state.cpu + "%"`.

Условие можно написать двумя способами, как вам удобнее:

```facet
color: state.active ? "#a7cbe7" : "#20272c"
color: if state.active then "#a7cbe7" else "#20272c"
```

Оба работают в свойствах любого типа, включая цвета и имена перечислений.

## Обработчики

Свойство, принимающее событие (`on_click`, `on_change`, `on_submit` или `onPress` у компонента), понимает три формы:

```facet
on_click: () => actions.open(app.id)          // лямбда
on_change: actions.search                     // функция: получает то, что передаёт vw
onPress: actions.select(tab.id)               // вызов: выполняется по событию, а не сейчас
```

Лямбды принимают параметры (`(value) => actions.set(value)`) и могут содержать несколько инструкций:

```facet
on_click: () => {
    let name = app.name
    actions.remember(name)
    actions.open(app.id)
}
```

Обработчик копирует локальные переменные, которые использует (включая переменные циклов), а до параметров view добирается как до живых объектов, так что `actions` и `state` никогда не копируются. Тело на C++ — см. [`() => cpp { … }`](/ru/facet/cpp/#блоки-c).
