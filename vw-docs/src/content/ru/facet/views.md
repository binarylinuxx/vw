## Импорты

```facet
let [ vw.ui as ui, vw.layout as layout ] in
```

Файл начинается с перечисления своих модулей. В `vw.ui` — поверхности, фигуры, текст, картинки, поля и [элементы управления](/ru/facet/controls/); в `vw.layout` — строки, колонки, сетки и списки. Любой другой модуль — это [модуль компонентов на C++](/ru/facet/cpp/#модули-компонентов), например дизайн-система.

## View

```facet
view Settings(state, actions) { … }
```

View становится шаблоном функции C++: `views::Settings(ui, state, actions)`. Его параметры могут быть любого типа; clang проверяет, как view их использует. В одном файле может быть сколько угодно view.

- View, тело которого — один `ui.Surface(…)`, это целая поверхность: вызывайте его из функции сборки `vw::App`.
- Любой другой view возвращает `vw::Widget`, который можно раскладывать из C++ или использовать как [компонент](/ru/facet/cpp/#нативные-виджеты) другого view.

## Элементы

```facet
layout.Column(gap: 8, padding: 16) {
    ui.Text(text: "Заголовок", size: 20, weight: bold)
    ui.Text("Короче: первый аргумент может быть позиционным")
}
```

Элемент — это `module.Name(аргументы) { дети }`. Аргументы именованные (`size: 20`); `text` у `Text` и `path` у `Image` могут также идти первыми без имени. Дети — в фигурных скобках. Каждое свойство проверяется: неизвестное — это ошибка со списком того, что у элемента есть.

[Справочник элементов](/ru/facet/elements/) перечисляет все элементы и их свойства.
