## vw::Input

| Поле | Вызывается с |
| --- | --- |
| `on_click` | `ClickEvent {x, y, button}` — 272 левая, 273 правая, 274 средняя |
| `hover` | `Hover {color, scale, duration}`: оттенок и масштаб, анимируемые без пересборки |
| `on_hover` | `bool inside` — вход и выход, даже под другими виджетами; после этого пересборка |
| `on_drag_start`, `on_drag`, `on_drag_end` | `DragEvent {x, y, start_x, start_y, dx, dy, delta_x, delta_y, button, cancelled}` |
| `on_scroll` | `ScrollEvent {x, y, delta}` — положительное значение прокручивает вниз |
| `on_scroll_x` | `ScrollEvent` вбок: наклон колёсика, тачпады, горизонтальные свайпы; положительное — вправо |
| `on_touch` | `TouchEvent {phase, id, x, y, start_x, start_y, fingers}` — пальцы как есть, см. [Касания](#касания) |
| `drag_button` | какая кнопка тянет (BTN_LEFT, 272) |

Клики получает самый верхний виджет под указателем. Перетаскивание захватывает указатель до отпускания. Обработчики обычно меняют ваше состояние; сцена пересобирается после каждого обработчика.

## Касания

Сенсорные экраны управляют теми же обработчиками, одним пальцем за раз, и ничего дополнительно писать не нужно:

| Палец | Становится |
| --- | --- |
| касание | `on_click` (кнопка 272) у виджета под пальцем |
| перетаскивание, начатое на чём-то с `on_drag…` | этим перетаскиванием, как мышью |
| перетаскивание, начатое в текстовом поле | движением курсора и выделением |
| свайп в любом другом месте, дальше 10 px | прокруткой того, что под пальцем: вверх-вниз — в `on_scroll`, `scrollbox` и `listview`, вбок — в `on_scroll_x`; нажатие тогда не кликает |

Пока виджета касаются, у него вид наведения, а после того как палец поднят, ничего не остаётся наведённым. Если композитор забирает касание под свой жест, нажатие сбрасывается, а перетаскивание завершается с `cancelled`. Так виджетами управляет один палец за раз; остальные пальцы уходят в `on_touch` или никуда.

### Несколько пальцев: on_touch

Виджет с `on_touch` получает свои пальцы как есть — каждый, что опустился на него, со своим `id`, от `down` через `motion` до `up` (или `cancel`). Кликать, тащить или прокручивать его они при этом не будут. `fingers` считает пальцы, которые держат виджеты с `on_touch`, так что щипок — это два из них:

```cpp
std::map<std::int32_t, std::pair<double, double>> held;
double zoom = 1, from_spread = 0, from_zoom = 1;
const auto spread = [&] {
  auto a = held.begin()->second, b = std::next(held.begin())->second;
  return std::hypot(a.first - b.first, a.second - b.second);
};
// в функции сборки
ui.rectangle({.width = 200 * zoom, .height = 200, .input = {.on_touch = [&](const vw::TouchEvent& touch) {
  using Phase = vw::TouchEvent::Phase;
  if (touch.phase == Phase::up || touch.phase == Phase::cancel) { held.erase(touch.id); return; }
  held[touch.id] = {touch.x, touch.y};
  if (touch.phase == Phase::down && held.size() == 2) { from_spread = spread(); from_zoom = zoom; }
  if (held.size() == 2 && from_spread > 0) zoom = from_zoom * spread() / from_spread;
}}});
```

Движение пересобирает со следующим кадром, как перетаскивание; остальные фазы — сразу.

## Экранная клавиатура

Текстовые поля говорят по `text-input-v3`, так что экранная клавиатура (squeekboard, maliit, любой метод ввода) работает с ними, как с любым приложением:

- Фокус на текстовом поле вызывает клавиатуру; уход из поля, когда ни у одного поля нет фокуса, убирает её. Касание поля с фокусом возвращает убранную клавиатуру.
- То, что клавиатура ещё составляет, видно в поле по мере набора и заменяется, когда она его отправляет; в `on_change` оно приходит как набранный текст.
- Пароли и поля экрана блокировки помечены как секретные: клавиатура ничего не узнаёт об их тексте и не подсказывает для них слова.
- Собственный Enter клавиатуры отправляет поле: `on_submit` или разблокировка на экране блокировки.
- Клавиатуре сообщается, где нарисован курсор, чтобы она его не закрывала.

## Клавиатура

```cpp
ui.keyboard([&](const vw::KeyEvent& key) {
  if (key.name == "Escape") { open = false; return true; }
  if (key.name == "Down") { ++selected; return true; }
  return false;  // достанется текстовому полю с фокусом
}, vw::Keyboard::exclusive);
```

У `KeyEvent` есть `keysym`, `name` (имена xkb: `Escape`, `Return`, `Down`, `a`, `F5`), `text` (UTF-8, если есть), флаги модификаторов `ctrl`, `alt`, `shift`, `super` и `repeat` для событий автоповтора. Режим действует для layer-поверхностей; см. [Оболочки и layer-поверхности](/ru/guides/shells/#клавиатура).
