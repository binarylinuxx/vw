---
title: App и цикл
description: vw::App владеет поверхностями, источниками событий и циклом. vw/vw.hpp подключает весь публичный API.
---

```cpp
#include <vw/vw.hpp>

int main() {
  vw::App app;
  app.surface(build_bar)
     .surface(build_launcher)
     .on_event(vw::hyprland::event_fd(), vw::hyprland::drain_events);
  return app.run();
}
```

## vw::App

| Член | Значение |
| --- | --- |
| `App()` / `App(build)` | пустое приложение или приложение с одной поверхностью |
| `surface(build)` | добавляет поверхность, которую строит `void(vw::Ui&)`; можно вызывать цепочкой |
| `per_output(build, most = 8)` | по поверхности на каждый монитор, её строит `void(vw::Ui&, const vw::Output&)` и показывает на этом мониторе; см. [панель на каждый монитор](/ru/guides/shells/#панель-на-каждый-монитор) |
| `on_event(fd, drain)` | пересобирает все поверхности, когда `fd` читаем и `drain()` вернул true; отрицательные fd игнорируются |
| `run()` | работает до закрытия; возвращает `EXIT_SUCCESS` или печатает ошибку и возвращает `EXIT_FAILURE` |
| `build()` | один раз строит первую поверхность — проверить сцену без Wayland |

## Когда поверхность пересобирается

| Причина | Какие поверхности |
| --- | --- |
| ввод на поверхности | эта сразу, остальные до того, как цикл уснёт |
| сработал источник событий | все |
| монитор подключили, отключили или сменили режим | все |
| прошёл её `refresh_interval` (по умолчанию 1 с) | только эта |
| frame callback во время анимации | только эта |
| SIGHUP | все |

SIGINT и SIGTERM аккуратно завершают `run()`.

## Уровнем ниже

`vw::SceneSource` — интерфейс, которым управляет цикл: `build()` возвращает `vw::Scene`, `event_sources()` перечисляет fd, а `watch_directory()`/`affects(name)` позволяют источнику пересобираться при правке файлов (Lua-фронтенд так делает горячую перезагрузку). `vw::run(source)` запускает один источник. Большинству программ это не нужно.

## Состояние хоста

Функции в `vw/host.hpp` описывают строящуюся поверхность:

| Функция | Возвращает |
| --- | --- |
| `vw::surface_size()` | размер строящейся layer-поверхности после configure, `{0, 0}` до первого configure |
| `vw::toplevel_size()` | размер окна после configure |
| `vw::lock_surface_context()` | ширину, высоту и имя монитора строящейся поверхности блокировки |
| `vw::session_locked()`, `vw::session_authentication_failed()` | состояние блокировки |
| `vw::focus_grab_state()` | доступен ли и активен ли захват фокуса zwwm |

## Мониторы

`vw/outputs.hpp` перечисляет мониторы. Размеры логические: столько измеряет layer-поверхность во всю ширину на этом мониторе — это единицы, в которых рисует vw.

| Функция | Возвращает |
| --- | --- |
| `vw::outputs()` | все подключённые `vw::Output` в порядке композитора |
| `vw::output(name)` | монитор с именем `name` или `std::nullopt` |
| `vw::output_event_fd()`, `vw::drain_output_events()` | источник изменений; `App::run()` уже следит за ним |

| Поле `vw::Output` | Значение |
| --- | --- |
| `name` | разъём: `DP-1`, `eDP-1`, `HDMI-A-1` |
| `description` | обычно производитель и модель |
| `x`, `y` | логическое положение в раскладке мониторов |
| `width`, `height` | логический размер |
| `pixel_width`, `pixel_height` | текущий режим |
| `scale` | пикселей на логическую единицу, дробные масштабы тоже |
| `refresh` | мГц: `60000` — это 60 Гц |
