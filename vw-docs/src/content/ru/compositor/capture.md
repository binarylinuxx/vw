## Мониторы — `vw/capture.hpp`

`vw::capture_output({.output, .region, .cursor})` возвращает `vw::Bitmap` с тем, что показывает монитор, через wlr-screencopy (zwwm и другие композиторы в стиле wlroots). Рисуйте его через `ui.image({.bitmap = shot, .width = 320, .height = 180, .fit = vw::ImageFit::cover})`; vw уменьшает картинку один раз и переиспользует её, пока пиксели не изменились.

| Поле | Значение |
| --- | --- |
| `output` | имя разъёма, например `HDMI-A-1`; пустое — первый монитор |
| `region` | `{x, y, width, height}` в логических координатах монитора; не задано — весь монитор |
| `cursor` | включить указатель |

Полный захват 1080p занимает примерно один кадр, так что делайте его по интервалу обновления или когда событие говорит, что экран изменился, а не в каждой сборке.

## Окна

zwwm захватывает отдельные окна для клиентов, которые докажут, что принадлежат сеансу: при запуске он пишет случайный токен в `$XDG_RUNTIME_DIR/<WAYLAND_DISPLAY>.capture-token`, читаемый только вами, и называет его в `ZWWM_CAPTURE_TOKEN`. vw сам предъявляет его через `zwwm_capture_access_v1`; настраивать ничего не нужно.

| Функция | Значение |
| --- | --- |
| `window_capture_available()` | zwwm разрешил захват окон |
| `capture_windows()` | `id`, `title`, `app_id`, `x`, `y`, `width`, `height`, `output`, `activated`, `minimized`, `maximized`, `fullscreen` |
| `capture_window(id, cursor)` | окно в его собственном размере, без декораций, в том числе на скрытых тегах |
| `capture_event_fd()`, `drain_capture_events()` | изменился список окон или окно; для `app.on_event` |

Обзор (overview) захватывает каждое окно при открытии и затем с медленным интервалом; fd событий говорит, когда поменялись заголовки, размеры или список.
